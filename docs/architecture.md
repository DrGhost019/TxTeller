## ۲. میزبانی دائمی، همیشه‌روشن و کاملاً رایگان (100% Free Forever)

برای برآورده‌کردن شرط شما مبنی بر **پایداری همیشگی، آنلاین بودن ۲۴ ساعته و هزینه صفر**:

| بخش | پلتفرم پیشنهادی | ویژگی‌ها و مزایای رایگان |
| :--- | :--- | :--- |
| **پایگاه داده (PostgreSQL)** | **Supabase** (Free Tier) | ۵۰۰ مگابایت حافظه (کافی برای ده‌ها سال تراکنش شخصی)، پشتیبان‌گیری خودکار، پنل وب عالی، و قابلیت Connection Pooling |
| **بک‌اند و داشبورد وب** | **Vercel** (Hobby Plan) | هاست بدون محدودیت خاموشی (Serverless)، گواهی رایگان HTTPS، اتصال خودکار به گیت‌هاب |
| **بات تلگرام و گزارش‌ها** | **Vercel Serverless Webhook + Vercel Cron** | نیاز به خرید یا نگهداری سرور جداگانه نیست! بات با وب‌هوک تلگرام روی خود Vercel اجرا می‌شود و گزارش‌های روزانه با تسک زمان‌بندی‌شده رایگان Vercel Cron فعال می‌گردند. |

> [!TIP]
> با پیاده‌سازی ربات بر پایه‌ی **Telegram Webhook** به جای Long Polling، کل سیستم درون یک پروژه واحد Next.js روی Vercel قرار می‌گیرد. به این ترتیب هرگز نیازی به نگرانی از خاموش شدن سرور یا پرداخت هزینه سرور نخواهید داشت.

## ۳. سازوکار دسته‌بندی و ثبت هوشمند پذیرنده/فروشگاه در تلگرام

چون در متن پیامک بانک شهر نام فروشگاه ذکر نمی‌شود، تجربه کاربری با یک جریان تعاملی دوسطحی در بات تلگرام به شکل زیر پیاده‌سازی می‌شود:

### گام اول: ارسال اعلان آنی به تلگرام
به محض انجام تراکنش، بات پیام زیر را همراه با دکمه‌های شیشه‌ای دسته‌بندی می‌فرستد:

> 🔔 **تراکنش جدید بانک شهر**  
> 💳 **نوع:** خرید با کارت  
> 💰 **مبلغ:** ۳۶۰,۹۰۰ تومان (۳,۶۰۹,۰۰۰ ریال)  
> 🏦 **مانده:** ۵۰,۹۵۷,۶۵۵ تومان  
> 🕒 **زمان:** ۱۴۰۵/۰۸/۲۳ - ۱۷:۱۸:۰۵  
>  
> *لطفاً دسته‌بندی این هزینه را انتخاب کنید:*

```
[ 🍔 خوراک روزانه ]       [ 🚗 حمل و نقل ]
[ 🏠 مسکن و قبوض ]       [ 🧴 ملزومات خانه ]
[ 👕 شخصی و سلامت ]     [ ☕ تفریح و سرگرمی ]
[ 💳 اقساط و بدهی ]     [ 📦 سایر / متفرقه ]
```

### گام دوم: ثبت دسته‌بندی و درخواست نام پذیرنده / فروشگاه
با لمس دکمه دسته‌بندی (مثلاً `🚗 حمل و نقل`)، دسته‌بندی فوراً در دیتابیس ثبت شده و پیام زیر نمایش داده می‌شود:

> ✅ دسته‌بندی روی **🚗 حمل و نقل** تنظیم شد.  
> 🏬 **نام فروشگاه یا پذیرنده چیست؟** (مثلاً: *اسنپ*، *تپسی*، *هایپرمی*)  
> *(می‌توانید نام را تایپ کرده و بفرستید، یا دکمه رد شدن را بزنید)*

```
[ ⏭ رد کردن (بدون نام) ]
```

### گام سوم: تکمیل نهایی اطلاعات
* **اگر متنی ارسال کنید** (مانند «اسنپ» یا «نانوایی»): فیلد `merchant` تراکنش به آن نام به‌روزرسانی شده و پیام تایید نهایی نمایش داده می‌شود:  
  *«✨ تراکنش با موفقیت به عنوان [🚗 حمل و نقل - اسنپ] نهایی شد.»*
* **اگر دکمه `[ ⏭ رد کردن ]` را بزنید**: فیلد `merchant` خالی باقی مانده و فرآیند با همان دسته‌بندی پایان می‌یابد.

## ۴. بررسی جامع محدودیت‌های Supabase در پلن رایگان (آیا مانع خواهد بود؟)

پلن رایگان (Free Tier) سرویس **Supabase** برای مصرف شخصی کاملاً پاسخگو است و نه تنها مانع نیست، بلکه یک انتخاب عالی به شمار می‌آید. بررسی دقیق محدودیت‌ها:

| پارامتر | سقف پلن رایگان Supabase | نیاز واقعی سامانه TxTeller | ارزیابی |
| :--- | :--- | :--- | :---: |
| **حجم دیتابیس** | ۵۰۰ مگابایت (500 MB) | هر تراکنش ~۴۰۰ بایت. ۱۰,۰۰۰ تراکنش ~ ۴ مگابایت | **بدون مشکل** (کافی برای بیش از ۵۰ سال) |
| **ترافیک خروجی (Egress)** | ۲ گیگابایت در ماه | کمتر از ۵۰ مگابایت در ماه | **بدون مشکل** |
| **تعداد کانکشن‌ها** | ۶۰ مستقیم / ۲۰۰ کانکشن با Pooler | حداکثر ۲ تا ۵ کانکشن همزمان | **بدون مشکل** |
| **تعداد پروژه‌ها** | ۲ دیتابیس فعال همزمان | ۱ دیتابیس برای پروژه کافی است | **بدون مشکل** |

### نکته کلیدی در پلن رایگان Supabase: تعلیق در صورت عدم فعالیت (7-Day Pause)
* **قانون Supabase**: پروژه‌های رایگان اگر به مدت **۷ روز متوالی** هیچ کوئری یا ترافیکی نداشته باشند، به حالت خواب (Pause) می‌روند.
* **راهکار TxTeller (جلوگیری ۱۰۰٪ قطعی)**:  
  سامانه TxTeller مجهز به **Vercel Cron** است که هر شب رأس ساعت ۲۳:۰۰ گزارش مالی روزانه را برای تلگرام استخراج می‌کند. این کوئری روزانه دیتابیس را زنده نگه می‌دارد و مانع از به خواب رفتن دیتابیس می‌شود.
* *(جایگزین معادل)*: سرویس **Neon.tech** نیز پلن رایگان با ۰.۵ گیگابایت ارائه می‌دهد که بر پایه Serverless Postgres است و حتی اگر بخوابد، با اولین کوئری ظرف ۵۰۰ میلی‌ثانیه بیدار می‌شود. هر دو پلتفرم با `schema.prisma` ما سازگاری کامل دارند.

## ۵. مشخصات نقاط دسترسی بک‌اند (API Contracts)

### ۱. دریافت پیامک خام از اندروید
* **متد و آدرس**: `POST /api/messages`
* **هدر امنیتی**: `x-api-key: <SECRET_KEY>`
* **بدنه درخواست (JSON)**:
  ```json
  {
    "sender": "Bank Shahr",
    "body": "*بانک شهر*\nخريد با کارت\nبرداشت از:ACCOUNT_NUMBER\nمبلغ:3,609,000ريال\nموجودي:509,576,551 ريال\n1405/08/23 17:18:05"
  }
  ```
* **پاسخ موفق (`200 OK`)**:
  ```json
  {
    "success": true,
    "transactionId": "d3b07384d113edec49eaa6238ad5ff00",
    "amount": "3609000",
    "balance": "509576551",
    "type": "PURCHASE"
  }
  ```

### ۲. دریافت تراکنش‌ها (برای داشبورد وب و بات)
* **متد و آدرس**: `GET /api/transactions`
* **پارامترهای جستجو (Query Params)**:
  * `from` / `to`: فیلتر بازه تاریخی
  * `type`: نوع تراکنش (`PURCHASE`, `TRANSFER_OUT`, ...)
  * `categoryId`: شناسه دسته‌بندی
  * `limit` / `offset`: صفحه‌بندی

### ۳. تغییر دسته‌بندی و نام پذیرنده تراکنش (از طریق کلیک در تلگرام یا وب)
* **متد و آدرس**: `PATCH /api/transactions/:id`
* **بدنه درخواست (JSON)**:
  ```json
  {
    "categoryId": "c0a80123-uuid-daily-food",
    "merchant": "اسنپ",
    "note": "سفر از محل کار به منزل"
  }
  ```

### ۴. دریافت آمارهای ماهانه و خلاصه‌ها
* **متد و آدرس**: `GET /api/stats`
* **خروجی**:
  ```json
  {
    "currentBalance": "509576551",
    "totalSpentThisMonth": "18450000",
    "totalIncomeThisMonth": "32000000",
    "spendingByCategory": [
      { "name": "خوراک روزانه", "amount": "8200000", "percent": 44.4 },
      { "name": "حمل و نقل", "amount": "4150000", "percent": 22.5 }
    ]
  }
  ```

### ۵. وب‌هوک بات تلگرام
* **متد و آدرس**: `POST /api/telegram/webhook`
* دریافت آپدیت‌ها و رویداد کلیک روی دکمه‌های شیشه‌ای دسته‌بندی و فرامین متنی (`/start`, `/balance`, `/today`, `/month`).
