# مشخصات فنی موتور تحلیل پیامک و الگوهای بانک شهر (Regex Specification)

این مستند قوانین پیش‌پردازش، فیلتر امنیتی محلی و الگوهای استخراج داده (Regex) برای کلیه پیامک‌های بانک شهر را به صورت رسمی تعریف می‌کند.

---

## ۱. نمونه پیامک‌های واقعی بررسی‌شده

### الف) پیامک‌های معتبر مالی (تایید شده برای پردازش)
1. **انتقال وجه کارتی (برداشت)**:
   ```text
   *بانک شهر*
   انتقال وجه کارتي
   برداشت از:ACCOUNT_NUMBER
   مبلغ:2,511,000ريال
   موجودي:513,185,551 ريال
   1405/08/23 08:29:08
   ```
2. **خرید با کارت (برداشت)**:
   ```text
   *بانک شهر*
   خريد با کارت
   برداشت از:ACCOUNT_NUMBER
   مبلغ:3,609,000ريال
   موجودي:509,576,551 ريال
   1405/08/23 17:18:05
   ```
3. **انتقال وجه کارتی (واریز)**:
   ```text
   *بانک شهر*
   انتقال وجه کارتي
   واريز به:ACCOUNT_NUMBER
   مبلغ:3,200,000ريال
   موجودي:536,371,151ريال
   1405/08/19 21:04:45
   ```
4. **برداشت وجه از خودپرداز (ATM)**:
   ```text
   *بانک شهر*
   برداشت از کارت
   برداشت از:ACCOUNT_NUMBER
   مبلغ:2,010,000ريال
   موجودي:546,957,820 ريال
   1405/07/25 12:53:14
   ```

### ب) پیامک‌های ردشده (فیلتر امنیتی و غیرمالی)
1. **رمز پویا (OTP) - فیلتر و حذف قطعی**:
   ```text
   *بانک شهر*
   انتقال به 585983*3277
   مبلغ: 2,500,000 ريال
   رمز: 529000
   زمان اعتبار رمز: 08:30:53
   تاريخ: 1405/08/23 08:28:53
   ```
   *علت رد*: فاقد برچسب `موجودی:` است و دارای برچسب‌های `رمز:` و `زمان اعتبار رمز:` می‌باشد.
2. **اطلاعیه زیرساخت و قطعی سامانه**:
   ```text
   بانک شهر
   مشتری گرامی به منظور بروزرسانی زیرساخت ها...
   ```
   *علت رد*: فاقد برچسب‌های مالی `مبلغ:` و `موجودی:`.
3. **اعلان ورود به همراه بانک**:
   ```text
   *بانک شهر*
   ورود به همراه شهر
   تاريخ : 1405/8/30
   ساعت : 13:48:59
   ```
   *علت رد*: فاقد برچسب‌های مالی `مبلغ:` و `موجودی:`.

## ۲. الگوریتم فیلترینگ محلی در اندروید (Local Whitelist Gate)

پیش از ذخیره یا ارسال پیامک به سرور، پیامک دریافتی در `BroadcastReceiver` ارزیابی می‌شود:

```kotlin
fun shouldProcessSms(sender: String, body: String): Boolean {
    // 1. بررسی نام فرستنده (در صورت ارسال با Alphanumeric ID)
    val isBankShahrSender = sender.contains("Bank Shahr", ignoreCase = true) || 
                            body.contains("*بانک شهر*")
    if (!isBankShahrSender) return false

    // 2. شرط طلایی: حتما باید شامل مبلغ و موجودی باشد
    val hasAmount = body.contains("مبلغ:") || body.contains("مبلغ :")
    val hasBalance = body.contains("موجودي:") || body.contains("موجودی:") || 
                     body.contains("موجودي :") || body.contains("موجودی :")
    if (!hasAmount || !hasBalance) return false

    // 3. لایه محافظتی ضد رمز پویا (Blacklist چک ثانویه)
    val isOtp = body.contains("رمز:") || 
                body.contains("رمز پویا") || 
                body.contains("زمان اعتبار رمز") ||
                body.contains("کد تایید")
    if (isOtp) return false

    return true
}
```

## ۳. قوانین نرمال‌سازی متن (Text Normalization)

پیش از اعمال عبارات باقاعده (Regex)، متن باید استانداردسازی شود:

1. **حروف عربی به فارسی**:
   * `ي` (U+064A) $\rightarrow$ `ی` (U+06CC)
   * `ك` (U+0643) $\rightarrow$ `ک` (U+06A9)
2. **اعداد فارسی/عربی به لاتین**:
   * `[۰-۹]` و `[٠-٩]` $\rightarrow$ `[0-9]`
3. **حذف کاراکترهای نامرئی**:
   * حذف Half-space (نیم‌فاصله `\u200C`) در صورت وجود میان کلمات کلیدی، یا پشتیبانی از آن در الگو.

## ۴. عبارات باقاعده استخراج فیلدها (Regex Engine)

پس از نرمال‌سازی متن، الگوی جامع زیر تمام داده‌ها را در قالب Named Capture Groups استخراج می‌کند:

### الگوی یکپارچه:
```regex
^\*بانک شهر\*\s*\n(?<title>[^\n]+)\s*\n(?<direction>برداشت از|واریز به):(?<account>\S+)\s*\nمبلغ:\s*(?<amount>[\d,]+)\s*ریال\s*\nموجودی:\s*(?<balance>[\d,]+)\s*ریال\s*\n(?<date>\d{4}\/\d{1,2}\/\d{1,2})\s+(?<time>\d{1,2}:\d{2}:\d{2})
```

### تفکیک گروه‌های استخراجی (Captured Fields):
| نام گروه | نوع داده | توضیحات | مقادیر نمونه |
| :--- | :--- | :--- | :--- |
| `title` | `String` | عنوان نوع تراکنش در متن بانک | `خريد با کارت`, `انتقال وجه کارتي`, `برداشت از کارت` |
| `direction` | `String` | جهت ورود/خروج پول | `برداشت از` (خروج), `واریز به` (ورود) |
| `account` | `String` | شماره کارت یا حساب مبدا/مقصد | `ACCOUNT_NUMBER` |
| `amount` | `BigInt` | مبلغ تراکنش (پس از حذف ویرگول‌ها) | `2511000` (ریال) |
| `balance` | `BigInt` | مانده نهایی حساب (پس از حذف ویرگول‌ها) | `513185551` (ریال) |
| `date` | `String` | تاریخ شمسی تراکنش | `1405/08/23` |
| `time` | `String` | ساعت دقیق تراکنش | `08:29:08` |

### نگاشت نوع تراکنش به مدل سیستمی (`TxType`):
* اگر `direction == "واریز به"`:
  * خروجی: `TRANSFER_IN`
* اگر `direction == "برداشت از"`:
  * اگر `title` شامل `خريد`: خروجی: `PURCHASE`
  * اگر `title` شامل `خودپرداز` یا `کارت` (در `برداشت از کارت`): خروجی: `ATM_WITHDRAWAL`
  * اگر `title` شامل `انتقال`: خروجی: `TRANSFER_OUT`
  * سایر موارد: خروجی: `WITHDRAWAL`
